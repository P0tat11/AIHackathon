# Little Ledger

A cheerful, kid-friendly goal planner for young business owners. Children enter their business, savings goal, and timeline, then track earnings against a day-by-day plan.

## Run it

Open `index.html` in a current browser. No build step or package install is required. The app stores the business plan and earnings in the browser's IndexedDB database on that device.

## What it does

- Creates a personal business goal plan with an optional partner.
- Splits the goal into daily earning targets and displays a day-by-day plan.
- Saves earnings as they are entered and updates overall and daily progress bars.
- Keeps data on the current device; use **Start over** to erase the saved plan.

For children ages 7–12. A grown-up should help with real-world money decisions.
